# DigiSprint

DigiSprint is an AI-powered Digital Marketing Assistant for Indian small businesses.

It is being built with Next.js App Router, TypeScript, Tailwind CSS, Supabase and Vercel.

## Version 1.0

The current foundation includes:

- New AI marketing assistant homepage
- Responsive dashboard foundation
- Plan architecture preview
- Shared marketing and product navigation
- Theme customisation inherited from the existing project
- Supabase-ready schema and environment contract

Live authentication, AI generation, file uploads and subscriptions are planned for later versions.

See `docs/architecture.md` for the current implementation boundary.
